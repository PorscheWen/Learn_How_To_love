## 0. 怎麼測

### 啟動

以實際建置路徑為準（落地後補齊）。測前先確認對齊 `game_guild.md` 的信任區間與結局條件。

### 存檔與解析度

| 項目 | 建議 |
|------|------|
| 解析度 | 至少測 **1280×720** 與 **1920×1080**（視窗／全螢幕各一次） |
| 顯示縮放 | Windows 縮放 100%／125% 各看一次字幕與立繪 |
| 存檔 | 各 Section 信任選擇前後、閘門前後、S09 留下／送走前各存一檔；讀檔確認 `trust`／三軸／flags |
| 章節 | 若有選章：S01～S10 皆可進；跳關後信任預設須合理（勿直接滿 12） |

### 閱讀時間與互動密度

- [ ] 執行 `python Renpy_game/tools/validate-reading-time.py`，S01～S07 最短選項路徑皆須 **≥5 分鐘**
- [ ] S08／S09 最短選項路徑皆須 **≥8 分鐘**，且增加內容集中在胸背帶與門線、巷口受驚與恢復、交接等待與決定回聲
- [ ] S10 的 A／B／C／D **每一條實際路線皆須 ≥5 分鐘**，不可用四條結局總字數相加冒充
- [ ] 實機計時從 Section 標題卡開始，到下一段標題卡或結局牌為止；一般閱讀速度測一次、快速閱讀再抽測一次
- [ ] 不以重複句、無事件日記或額外日常灌水；新增段落必須讓玩家更清楚看見「人做了什麼、狗如何回應、下一個選擇為何變重」

## 1. 信任系統（對照 game_guild §1）

### 1.1 數值 vs 體感

- [ ] 內部 `trust` 為整數 **0～12**（開發者／除錯可見即可）
- [ ] **畫面上不顯示大數字**；關係靠狗距離、耳尾、是否背對睡、予安內心一句話表達
- [ ] 單次選擇多為 **±1**；關鍵拍（如 S09）可 **±2**；不可一天暴衝到滿
- [ ] 荷包／請假等**風味選擇**少動 `trust`，改動壓力或班表 flags（game_guild §5）

### 1.2 三條累積軸

| 軸 | 含義 | 典型來源 | 抽樣檢查 |
|----|------|----------|----------|
| **Dist** | 是否逼近／硬抓 | S02～S04、S08 | ☐ 硬抓→距離變遠；蹲等→半步靠近 |
| **Tone** | 是否為牠切換語氣 | S05、S07 | ☐ 會議尖銳聲／放慢可感 |
| **Guard** | 外人靠近時站哪邊 | S06、S09 | ☐ 擋／塞回屋後果不同 |

- [ ] 結局看**總分區間**；風味看哪一軸最高或最低（變體文案有差即可，不必另開結局）

### 1.3 各 Section 建議淨變動

| Sec | 升信任行為 | 降信任行為 | 建議淨變動 | OK |
|-----|------------|------------|------------|-----|
| 01 | —（鋪墊） | — | 0 | ☐ |
| 02 | 蹲下等、不硬抓、願意暫時照顧 | 趕、硬抓、冷漠離開 | 0～+2／−1 | ☐ |
| 03 | 多次下樓看、輕聲、留水食 | 腳趕、吼、整晚不理 | ±1～2 | ☐ |
| 04 | 平行安靜、縮手、留在看得見處 | 硬抱合照、關浴室 | ±1～2 | ☐ |
| 05 | 脫耳機後放慢、抱開時輕 | 會議語氣吼狗、用力甩開 | ±1～2 | ☐ |
| 06 | 擋在中間、婉拒陌生人摸 | 塞回屋、強迫接受撫摸 | ±1～2 | ☐ |
| 07 | 「我還在」、接受被叫醒 | 「吵死了」關到客廳 | ±1～2 | ☐ |
| 08 | 停等、接受提早回家 | 硬拖達標、猛拉牽繩 | ±1～2 | ☐ |
| 09 | 留下、承認依賴 | 執意送走 | **+2／−2** | ☐ |

### 1.4 Ch1 結束信任區間（體感）

| 區間 | 稱呼 | 測試時狗／關係應有感覺 |

## 2. 軟分軌與閘門（對照 game_guild §2）

### 2.1 軟分軌（主幹固定，溫度變）

- [ ] **S01～S10 主幹都能走完**；低信任不擋推進、不觸發養死／Game Over
- [ ] 同一 Section：高／中／低信任只改狗行為、對白密度、互動難度——**不是完全不同的故事**
- [ ] 僅在 **S09、S10**（及結局）開硬分歧影響結局標籤；S07 為 Tone 軟分軌，不另開結局線

**S08「走到轉角就好」抽樣（必測）：**

| 進段 trust | 預期演出 |
|------------|----------|
| 低（≤3） | 狗全程貼牆；機車經過便僵住；適合提早回家 |
| 中（4～6） | 能走一半；需要多次停下等待 |
| 高（≥7） | 肯走到轉角；回家後主動喝水並靠著鞋睡 |

### 2.2 關鍵閘門

| 閘門 | 時機 | 條件 | 通過／未過預期 |
|------|------|------|----------------|
| **G1 進門權** | S03→S04 | `trust ≥ 2` 或選擇讓牠進門 | 未過時增加**大門外**場景，**之後仍進入 S04** |
| **G2 被選中** | S09 | `trust ≥ 5` 或玩家堅持留下 | 低信任仍可留下，但狗不強烈拒絕同事；選送走→結局 C |

- [ ] 閘門只改關係質地，**不阻止故事推進**

### 2.3 中段累積狀態（S05～S08）

| 狀態 | 預期表現 | OK |
|------|----------|-----|
| 持續高信任 | 較早跟到廚房、主動貼腿、外出恢復較快 | ☐ |
| 忽高忽低 | 靠近與退縮交替；修復更有重量 | ☐ |
| 持續低信任 | 不躲到她身後，也不信她能保護 | ☐ |

### 結局路線最短測法

建議至少跑 **4 條**（每結局一條）：

| 路線 | 操作摘要 | 預期結局 |
|------|----------|----------|
| 高信任留下 | S02～S08 偏「等／輕／擋／回來」；S09 留下；S08 不硬拖 | **A**（需 trust 10～12） |
| 中信任留下 | 有升有降，落在 4～9；S09 留下 | **B** |
| 任意信任送走 | 任意路徑；S09 執意交同事 | **C**（高信任送走可有 landmark） |
| 低信任留下 | 多選逼近／兇／關；仍 ≤3；S09 留下 | **D** |

```text
                    S09 留下？
                   /         \
                 是            否 →【C 送走】
                 |
           trust 區間
         /      |       \
      ≤3      4～9      10～12
       |        |          |
    【D 薄冰】【B 選定】【A 背靠】
```

## 4. 文字缺漏與字型

### 4.1 必查

- [ ] 所有玩家可見字為**繁體中文、台灣用語**（禁簡體／中國用語：視頻→影片、質量→品質、信息→資訊、空調→冷氣、曬貓→貼自家的貓）
- [ ] **形容詞／用語勿單字落地**：玩家可見敘事禁「尖／低／短／鬆／冷」等單字當情緒標籤；改寫成台灣口語雙字以上（例：尖→尖銳、開會時那種尖銳；低→放軟的低聲；短→急促／趕時間；鬆→鬆一口氣；冷→發冷／冷得醒過來）
- [ ] 敘事口吻維持**溫和中性、帶點感性**：不灑狗血、不說教、不用翻譯腔或刻意文青詞堆疊
- [ ] 無空白對白、無 `???`、無未替換 placeholder（`TODO`、`xxx`、`{dog}`）
- [ ] 省略號統一 `……`；少用 ASCII `...`
- [ ] 女主固定**予安**；狗預設**小7**（超商暱稱），玩家可改；取名前多用「牠」，改後用 `dogLabel(s)`，文案禁寫死
- [ ] 本版僅有敘事選項與 S05 取名；**不得出現小遊戲、牽繩操作、快問快答、計時或答題分數**
- [ ] **禁止**主題總結句（「這就是信任的開始」）
- [ ] 結局 C／D **不道德綁架、不羞辱玩家**

## 8. 對遊戲整體的建議（Steam 電子小說玩家視角）

> 標竿類型：選擇回聲（Telltale／LiS）、情感節奏（To the Moon／Spiritfarer）、日常治癒（Coffee Talk）、日系 VN（快進／log／存檔）、寵物向（狗是家人不是道具）。

### 8.1 玩家會立刻在意的點

| 面向 | Steam 玩家常說 | Version3 建議 |
|------|----------------|---------------|
| **開場** | 15 分鐘決定退款 | S01 空白節奏要「一個人剛剛好」；S02 後門一瞥必須想留下 |
| **選擇有沒有差** | 假選項最毒 | 升／降信任要在距離、pose、內心一句話上可感；軟分軌溫度要讀得出 |
| **信任條** | 刷數值很廉價 | **不顯示大數字**；結局用睡姿與距離說話 |
| **死局** | 養死＝差評炸彈 | **無 Game Over**；C／D 仍是完整受尊重的故事 |
| **文字** | 簡繁混／機翻＝差評 | 繁中台灣用語；予安像 26 歲上班族 |
| **節奏** | 太慢煩、太趕沒感覺 | 十段主幹固定；心裡話短；可快進 |
| **基調** | 宣傳治癒卻道德綁架 | 送走不羞辱；薄冰不懲罰 |
| **跨章** | 結局要有後果 | A～D 進 Ch2 溫度不同（game_guild §4） |

### 8.2 測試通過門檻（S01～S10）

| 門檻 | 條件 |
|------|------|
| Smoke | 友善路線無 P0，可走完 S01～S10 並進任一結局 |
| 可給朋友試 | Smoke＋無 P1（溫度錯／結局錯／缺字／重疊／時段錯） |
| 章節就緒 | 可給朋友試＋四結局皆可達＋G1／G2 行為正確＋trust 區間體感對 |
