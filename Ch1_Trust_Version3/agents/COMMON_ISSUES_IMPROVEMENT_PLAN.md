## 🎯 三個共通痛點 & 實施方案

### 痛點 #1：隱藏內容發現機制不夠明確

**現象**：
- 新玩家完成結局後，可能不知道「有新隱藏內容已解鎖」
- 隱藏內容的存在感不足，浪費了重玩價值
- 玩家可能因為「沒發現獎勵」而感到缺乏成就感

**影響範圍**：⚠️ 所有三個群體（特別是首次遊玩者）

## 💡 方案 1：隱藏內容解鎖「演出系統」

### 📋 實施清單

#### **第 1 步：結局結束後的解鎖演出**

**Ren'Py 代碼實施** (`script.rpy` 結局段落，以結局 A 為例)：

```python
# ===== 結局 A：背靠背 =====
label ending_ch1_back_to_back:
    scene black
    with fade
    
    # 結局動畫與對白...
    # (現有代碼保持不變)
    
    # [NEW] 解鎖演出開始
    pause 1.0
    
    # 彩帶/星星特效（視覺反饋）
    show ending_unlock_effect
    with dissolve
    
    # 解鎖提示文案（3 秒）
    show unlock_notification:
        pos (0.5, 0.5)
        alpha 0.0
    with dissolve
    play sound "sfx/unlock.ogg"  # 解鎖音效
    show unlock_notification with easein
    pause 3.0
    hide unlock_notification with easeout
    
    # 解鎖內容記錄
    $ persistent.unlocked_secret_content["dog_diary_a"] = True
    $ persistent.unlocked_secret_content["character_reflection_a"] = True
    $ persistent.unlocked_secret_content["friend_perspective_a"] = True
    
    # 隱藏內容計數器更新
    $ persistent.total_unlocked_content = len([k for k, v in persistent.unlocked_secret_content.items() if v])
    
    # 調用既有的解鎖函數
    call process_ending_unlock("A")
    
    # [END] 解鎖演出結束
    
    # 標題卡顯示
    scene black
    with fade
    show ending_title_card_a
    with dissolve
    pause 2.0
    
    return
```

```python
transform unlock_animation():
    alpha 0.0
    linear 0.5 alpha 1.0
    pause 3.0
    linear 0.5 alpha 0.0
```

#### **第 5 步：隱藏內容「分層解鎖」策略** ⭐ 推薦

改進：不是一次解鎖所有內容，而是分層展示：

```python
# 結局完成後的解鎖時間表
label process_ending_unlock(ending_id):
    if ending_id == "A":
        # 立即解鎖
        $ persistent.unlocked_secret_content["dog_diary_a"] = True
        
        # 延遲 24 小時虛擬時間後自動解鎖（或下次啟動遊戲時）
        $ persistent.unlock_schedule = {
            "character_reflection_a": 86400,  # 秒數
            "friend_perspective_a": 172800,   # 48 小時後
        }
    # 其他結局類似...
    
    return
```

這樣做的優勢：
- ✅ 延長玩家回到主選單的動力（每天都有新內容）
- ✅ 降低「一次全看」導致的飽和度
- ✅ 鼓勵玩家每天訪問主選單
- ✅ 增加長期參與感

## 🎯 最後的建議

這三個痛點的改善，核心思想是：

> **不同的玩家群體有不同的語言。用他們的語言說話，轉化率自然提升。**

- 🎮 **gamer_30** 說的語言：邏輯、系統、重玩價值
- 💚 **gamer_25_female** 說的語言：情感、共鳴、被看見
- 🌤️ **gamer_60_retired** 說的語言：時光、意義、陪伴

上架的成功，取決於這三個聲音都被正確地聽到。
