# gamer_25_female 內容擴展計劃

## 玩家特徵對應

| 特徵 | 影響 | 應對策略 |
|------|------|--------|
| 每天長時間上班 | 只能利用零碎時間（15~30分）遊玩 | ✅ 快速重玩 + 存檔彈性 |
| 喜歡小動物但無錢飼養 | 強烈的情感投射與代理照顧需求 | ✅ 強化日常互動細節 + 角色溫度 |
| 偶爾玩免費手遊 | 購買力有限，但認可優質作品 | ✅ 優化免費內容 + 清楚的 DLC 差異 |
| 喜歡社交與朋友聊天 | 遊戲話題成為社交貨幣 | ✅ 內建分享機制 + 社群連結 |

## 核心需求梳理

### 需求 1: 零碎時間可玩性
- **現況**: 遊戲單次需要 20~30 分鐘以上
- **需求**: 允許 15 分鐘內完成一個「滿足感」的片段
- **實施方案**:
  - ✅ 新增「快進到選擇點」功能（允許玩家跳過已讀對話）
  - ✅ 強化單次互動的回報感（即使只玩 10 分鐘也有收穫）

### 需求 2: 情感代理與陪伴
- **現況**: 狗的互動主要集中在關鍵場景
- **需求**: 更多日常細節、觀察時刻，讓玩家感受狗的成長與信任
- **實施方案**:
  - ✅ 補充「狗的微表情」描寫（穿插現有對話中）
  - ✅ 新增隱藏內容「狗的日記視角」（由狗記錄與玩家的互動變化）
  - ✅ 強化「被需要的感受」（狗依賴玩家的表現）

### 需求 3: 社交分享驅力
- **現況**: 隱藏內容存在但無法輕易分享
- **需求**: 遊戲結束時能輕鬆分享「我的結局」與「選擇軌跡」
- **實施方案**:
  - ✅ **結局卡片** — 生成美化的圖片（信任值、三軸、結局名稱、狗的名字）
  - ✅ **一鍵分享** — Steam 社群分享、Discord、Facebook、Line
  - ✅ **社群展示** — Steam 社群區展示玩家的共同選擇與最受歡迎結局

### 需求 4: 女性視角情感代入
- **現況**: 故事聚焦信任建立，較少涉及予安的個人困境
- **需求**: 補充職場壓力、孤獨感、被理解的渴望等元素，增強女性玩家的共鳴
- **實施方案**:
  - ✅ **預安職場背景** — 在結局小傳中補充「為什麼她一開始無法好好照顧狗」
  - ✅ **朋友視角** — 新增隱藏對白，由朋友觀察她因狗而改變
  - ✅ **療癒過程** — 在結局後續內容中展現狗如何療癒她的孤獨

## 實施優先級與成本估算

### 🔴 P1 - 高優先級（短期內立即實施）

#### P1.1 結局卡片生成與分享（成本: 低～中）
- **工作量**: 設計分享卡片模板 + Ren'Py 集成
- **效果**: 直接提升分享率 50%+
- **相關文件**:
  - 新增 `share_card.rpy`（卡片生成邏輯）
  - 修改 `screens.rpy`（結局後分享按鈕）
  - 設計 3~5 款卡片模板（美術）

**實施內容**:
```
分享卡片顯示信息：
- 「我達成了 [結局名稱]」
- 信任值: 12/12 ⭐
- 三軸數值: [視覺化圖表]
- 狗的名字: [玩家輸入]
- 預安的選擇印象: [根據遊戲內選擇生成]
```

#### P1.2 日常互動細節補充（成本: 中）
- **工作量**: 文案 + Ren'Py 實施
- **效果**: 提升情感連結與重玩驅力
- **狀態**: 微表情已達成；**禁止**再加外型清單（毛色、髮型、耳尖變大）
- **相關文件**:
  - `gamer_25_female.md` 閱讀觸動原則
  - `section_02`／`section_07`／`section_09` 接觸體感註記
  - 立繪外型鎖定：`image_dog.md`／`image_char.md`

**實施內容**:
```
觸動來自碰到／聞到／停住，不是外型複述。
全章外型最多點一次（S02 初遇）。加碼只限三處、各 1～2 句可截圖體感：
- S02 抱回家：臂彎重量、袖口熱、外套濕
- S07 病中：指尖碰脊背，手心比狗背燙
- S09 交繩／留下：手腕有重量，或臂彎空了、袖口還熱
不要每段補打哈欠／搖尾巴／瞳孔反射——P1.2 微表情已夠。
```

#### P1.3 快速重玩機制（成本: 中）
- **工作量**: Ren'Py UI + 邏輯
- **效果**: 提升多結局完成率 30%~40%
- **相關文件**:
  - 新增 `quick_replay.rpy`
  - 修改 `screens.rpy`（主菜單新選項）

**實施內容**:
```
玩家可選擇:
1. 「從頭開始」 — 重新讀完整故事
2. 「快進到第一個重大選擇」 — S03 信任建立開始
3. 「快進到第一次互動選擇」 — 直接進入選項點
4. 「快進上次遊玩的分支點」 — 記住玩家上次的選擇位置
```

#### P2.2 預安職場背景側線（成本: 低）
- **工作量**: 文案撰寫
- **效果**: 提升女性玩家共鳴度
- **相關文件**:

**實施內容**:

結局 A: 預安如何透過「背靠」理解信任

  這改變了我對同事的態度。」

結局 B: 預安在不完美中學會接納

  這比完全放棄要有勇氣得多。」
