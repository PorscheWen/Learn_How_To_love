# Section 03｜樓梯間的臨時國界

> Ch1 Trust · 第三人稱敘事稿  
> 閱讀約**五分鐘**｜今晚不算數——她以為  
> 場次 A 中段；與 S04 各留**一個**記憶點，勿寫成適應日記

**設計對齊（`game_guild.md` §0）**

| 項目 | 本段設定 |
|------|----------|
| 定位 | **歸來測試**（S03）；主軸仍是 **距離 Dist** |
| 信任變動 | 升：多次下樓、輕聲、留水食（**±1～2**）；降：腳趕、吼、整晚不理 |
| 篇幅 | 最短選項路徑約 **1,150 字／五至六分鐘**；一件事＝「她上樓又下來」 |
| 選擇 | **1 組信任**（下樓看／腳趕／整晚不理）＋可選風味（要不要留外套） |
| 閘門 | **G1 進門權** 在本段末埋下：`trust ≥ 2` 或玩家選讓牠進門 → 進 S04；未過則多一段樓梯間，**仍進 S04** |
| 記憶點 | 狗換窩位——更靠牆、更能看見電梯門 |
| 鉤子 | 清晨：狗在她房門外（自己決定國界線） |

---

電梯在一樓停住。予安用肩膀擋住門，把狗放在樓梯間的轉角——水泥地涼，燈管嗡嗡響，隔壁門縫底下有一條細細的光。

「今晚不算數。」她又說一次，像對合約蓋章。

她脫下外套鋪在地上，壓平皺褶。紙盤裡倒了半瓶水。狗縮在外套邊，鼻子嗅那股加班與關東煮混在一起的味道，沒有衝撞她，也沒有撒嬌——只是看著電梯門，像在記住一條會開合的邊界。

鄰居門縫的光亮了一下，又滅。

予安上樓。洗澡水開得很熱，蒸汽把鏡子糊成一片。她告訴自己：明天找人來、明天送走，明天讓日子恢復成只剩冰箱嗡嗡的夜晚。說出口的「明天」很短；她自己都聽得出來——短得像在趕時間。

她擦乾頭髮，還是下了樓。

第一次下樓：狗還在。窩的位置卻換了——更靠牆，更能看見電梯門打開的角度。外套被拖歪了一角。水盤少了兩口。

予安停在兩步外。狗耳朵動了一下，沒站起來，也沒退。

> ▷ **信任選擇（距離 Dist）— 本段唯一動 trust 的選項組**  
> **A｜蹲下，輕聲說「我還在」，再補一點水** → Dist＋／`trust +1`～`+2`；狗耳鬆一點  
> **B｜用腳趕進角落，提高音量「別擋路」** → Dist−／`trust −1`～`−2`；狗貼牆、耳平  
> **C｜看一眼就上樓，整晚不再下來** → Dist−／`trust −1`；清晨鉤子改為更遠的距離（門邊更遠／更警覺）

她蹲下去。膝蓋又響。

「我還在。」聲音低，句子不完整——不是上班的尖。「明天……再說。」

狗不懂句子。牠只聽語氣裡那一點「短」被拉長了一點點。鼻子伸向她的鞋尖，停在半公分外，沒碰。

予安上樓。夜裡，電梯又在一樓停了一次。門才打開，樓梯間便傳來爪子急促刮過水泥的聲音，隨即縮回牆角。

她從床上坐起來。她知道狗正把身體挪到能看清來人的位置；也知道電梯每響一次，牠就得重新判斷一次要不要逃。

予安走到房門後，手握上門把。電梯門在樓下合起來，馬達往上爬了一層，又一層。她沒有開門，只留下一道縫。走廊的光切進房裡，也把她今晚還會不會回去，留在門檻上。

本來就只是一晚。

清晨。鬧鐘還沒響。

走廊有極輕的抓門聲，或者只是她夢到的。她打開房門——

狗睡在門外墊子上。不知誰開過門；或者狗自己找到縫。牠的背朝走廊，臉朝她的門，像自己畫了一條國界：外面可以吵，裡面要有人。

予安蹲在門檻上，手停在半空。

「今晚……」她聽見自己說，然後改口：「算了。」

> ▷ **閘門 G1（進門權｜風味可動 trust）**  
> **讓牠進來** → 進 S04；若 `trust ≥ 2` 或本段選 A，狗較肯跨門檻  
> **先留在門外／樓梯間再一天** → 仍進 S04，但開場多「門縫對望」；關係質地更薄，不卡關

她讓開門縫。狗看著門內的地板，看著她，又看向電梯方向——最後把前腳跨進去半步，停住，像在問：這算不算數。

予安沒有回答。她只是把門開大一點。

## 設計註記（對齊 `game_guild.md`）

- **一件事：** 上樓→是否回來→狗仍在重新判斷出口。夜間用電梯與爪聲維持懸念，禁止再寫洗澡儀式、網購清單、長獨白。
- **記憶點（唯一）：** 窩位換成「更靠牆、更能看見電梯」。
- **關鍵拍：** 「明天就送走」語氣短 → 選 A 時拉長為「我還在」。
- **鉤子：** 清晨房門外＝狗自己決定國界 → 銜接 S04 進門。
- **G1：** 未過不擋主幹；只改 S04 開場溫度。
- **軟分軌：** S02 若 `vet_first`，本段開場可改「從診所回家後的樓梯間／門口」，節拍不變。
- **銜接 S04：** 門縫半步 → **共享同一種安靜**。

### 建議 trust 結算

| 玩家行為 | 建議 |
|----------|------|
| A＋多次下樓＋留水 | `trust +2` |
| A 但只下樓一次 | `trust +1` |
| B 腳趕／吼 | `trust −1`～`−2` |
| C 整晚不理 | `trust −1`；清晨距離更遠 |
