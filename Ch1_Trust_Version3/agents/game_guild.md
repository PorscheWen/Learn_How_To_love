## 0. 節奏與篇幅（電子書基線）

### 0.1 目標時間

| 單位 | 建議 | 說明 |
|------|------|------|
| **整章 Ch1** | **60～85 分鐘** | 主線一次讀完；十段主幹固定，**不增 S11／S12** |
| **單段 Section** | **至少 5 分鐘** | S08／S09 互動高潮各約 **8 分鐘**；其餘段不得低於 5 分鐘 |
| **開場鉤子** | **≤15 分鐘** | S01＋S02 結束前，玩家必須「想留下這隻狗」 |

### 0.2 文字密度（每段）

| 項目 | 建議 |
|------|------|
| 主敘事 `text` | **400～700 字**（可分段顯示；超過先砍重複描寫） |
| 心裡話 `sub` | 短句；一場景一至兩句 |
| 選項 | **2～3 個**；其中**最多 1 個**動 `trust`（其餘風味／路徑 flags） |
| 事件結構 | **一件事＋一個信任拍＋一個鉤子**；勿寫成「適應日記」連續兩段 |

### 0.3 自然存檔點（建議玩家分 2～3 次讀完）

| 場次 | 範圍 | 約時長 |
|------|------|--------|
| A | S01～S04 | 20～25 分 |
| B | S05～S08 | 20～25 分 |
| C | S09～S10 | 15～20 分 |

### 0.4 各段篇幅錨點

| Sec | 定位 | 建議閱讀 | 備註 |
|-----|------|----------|------|
| 01 | 空白節奏 | **5～6 分** | 只立「一個人剛剛好」；以搜尋／刪除與空屋細節加深，不寫完整加班日記 |
| 02 | 相遇鉤子 | **5～7 分** | **15 分鐘退款線**在此收束；蹲等／不硬抓須可感 |
| 03～04 | 大門＋安靜 | 各 **5～7 分** | 各留一個記憶點，勿雙雙寫滿 |
| 05～07 | 中段軟分軌 | 各 **5～7 分** | 選擇高峰依序為回授點名／鄰居持續壓力／發燒耳鳴；避免三段同拍 |
| 08 | 第一次外出 | **約 8 分** | 胸背帶、門線、巷口聲音、停等與返家均須可感 |
| 09 | 差點送走 | **約 8 分** | 理性清單、交接等待與留下／送走回聲構成情緒高峰 |
| 10 | 四結局落地 | 每條路線 **至少 5 分** | 共通物證＋不同睡姿；不可只用短結算文字 |

### 0.5 太長／太短怎麼調

| 體感 | 調法 |
|------|------|
| 整章 > 90 分 | 砍重複描寫；合併同類安靜日常；本版不以小遊戲補節奏 |
| 整章 < 35 分 | 加**回聲反應與狗行為**，不加新劇情段 |
| S01 悶、想跳 | 再砍鋪墊；店員那句鉤子提早到結帳前 |
| S03～S04 像拖 | 各留一個記憶點；刪「適應日記」式連寫 |

### 0.6 互動形式（Version3 鎖定）

- **不加入小遊戲、牽繩微互動或快問快答。**
- 玩家操作維持 Ren'Py 選項、取名與存讀檔；不新增計時、連點、分數條或答題結算。
- S08 的牽繩張力以文字、狗姿勢與既有 Dist 三選一表達，不另建操作層。
- 若節奏偏靜，優先調整段落長度、選項前蓄壓與選項後回聲，不用測驗或玩法填充。

### 0.7 電影化演出基線（不增加新事件）

每個 Section 優先整理成四個演出拍點：

1. **進場畫面：** 用空間、光線、人物站位或一個環境動作建立當下狀態；避免先用旁白解釋情緒。
2. **關鍵動作：** 選項前只聚焦一件可見事件，讓玩家操作距離、語氣、護衛、歸來或修復。
3. **反應鏡頭：** 選項後立即用狗的鼻尖、耳尾、呼吸、腳步、牽繩張力與 `far／mid／near` 回聲；不可只靠內心話或數值結算。
4. **離場鉤子：** 以一個物件、動作、聲音或未回答的話銜接下一段，不另加第二件完整事件。

落地限制：

- 細微動作必須是角色當下可見、可聽或可感的行為；少寫「牠開始信任她」等直接判讀。
- `pause` 只放在看見、受驚、選項後回聲與離場鉤子等轉折點；勿逐句停頓。
- 構圖變化優先沿用既有背景、人物左右站位及狗的 `far／mid／near`，不為每句新增立繪。
- 電影化是演出層，不改十段主幹、trust 門檻、flags 契約或互動形式。
- S02、S08 為已落地樣板；其餘 Section 套用時仍須遵守各段篇幅與「一件事＋一個信任拍＋一個鉤子」。

## 1. 信任怎麼累積（建議規格）

### 1.1 數值（系統內）vs 體感（畫面上）

| 層 | 建議 | 說明 |
|----|------|------|
| 內部 | `trust` 整數 **0～12** | 方便分支門檻 |
| 畫面 | **不顯示大數字** | 改用狗距離、耳尾、是否背對睡、予安內心一句話 |
| 單次選擇 | 多為 **±1**；關鍵拍可 **±2** | 避免一天暴衝到滿 |

### 1.2 三條累積軸

除了總分，另記三個 flags 軸；它們影響變體文案，不各自建立獨立結局：

| 軸 | 含義 | 典型來源 |
|----|------|----------|
| **距離 Dist** | 是否逼近／硬抓 | S02～S04、S08 |
| **頻率 Tone** | 是否願意為牠切換語氣 | S05、S07 |
| **護衛 Guard** | 外人靠近時站在哪一邊 | S06、S09 |

總 `trust` 表示關係溫度；結局看總分區間，演出風味看哪一軸最高或最低。

### 1.3 各 Section 建議信任變動

| Sec | 信任機會（升） | 信任風險（降） | 建議淨變動 |

| 01 | —（鋪墊） | — | 0 |

| 03 | 多次下樓看、輕聲、留水食 | 腳趕、吼、整晚不理 | ±1～2 |
| 04 | 平行安靜、縮手、留在看得見處 | 硬抱合照、關浴室 | ±1～2 |
| 05 | 脫耳機後放慢、抱開時輕 | 用會議語氣吼狗、用力甩開 | ±1～2 |

## 2. 依信任發展故事

### 2.1 採用軟分軌

不要讓每個 Section 都分成兩條完全不同的故事：

```text
主幹 10 Section 固定走完
  ├─ 每段依高／中／低信任改變狗的行為、對白與互動難度
  └─ 僅在 S09、S10 開啟影響結局標籤的硬分歧
     （S07 為 Tone 軟分軌：升／降信任與語氣，不另開結局線）
```

以 S08「走到轉角就好」為例：

| 進段 trust | 演出差異 |
|------------|----------|
| 低（≤3） | 狗全程貼牆；機車經過便僵住；適合提早回家 |
| 中（4～6） | 能走一半；需要多次停下等待 |
| 高（≥7） | 肯走到轉角；回家後主動喝水並靠著鞋睡 |

同一事件因關係溫度不同，讀感便會完全不同。

**S08 持久旗標（結局讀取）：**

| Flag | 寫入時機 | 用途 |
|------|----------|------|
| `s08_forced_walk` | 選「硬拖把一圈走完」 | `True` 時**不得**進結局 A；停等／提早回家寫 `False` |
| `s08_waited` | 樹下停等 | 風味／記憶 |
| `s08_returned_early` | 提早回家 | 風味／記憶 |

鞋邊睡記憶點：停等或提早回家成立；硬拖路徑改為門邊距離，不強制鞋邊睡。

### 2.2 關鍵閘門

| 閘門 | 時機 | 條件 | 通過／未過 |
|------|------|------|------------|
| **G1 進門權** | S03→S04 | `trust ≥ 2` 或選擇讓牠進門 | 未過時增加**大門外**場景質地，之後仍會進入 S04 |
| **G2 被選中** | S09 | `trust ≥ 5` 或玩家堅持留下 | 低信任仍可留下，但狗不會強烈拒絕同事；選送走則進結局 C |

閘門改變的是關係質地，不應阻止玩家推進故事。

### 2.3 中段發展

| 累積狀態 | S05～S08 的表現 | 玩家感覺 |
|----------|-----------------|----------|
| **持續高信任** | 狗較早跟到廚房、主動貼腿、外出恢復較快 | 我們正在長出來 |
| **忽高忽低** | 靠近與退縮交替；予安自責後嘗試修復 | 學愛是鋸齒狀的 |
| **持續低信任** | 狗不躲到她身後，也不相信她能保護自己 | 同住，卻仍像陌生室友 |

忽高忽低最有戲，能讓 S07 與 S09 的修復更有重量。

## 3. Ch1 四條分支結局

全部角色都活著；差異在於他們如何進入 Ch2。

### 結局 A｜背靠

- 標籤：`ending_ch1_back_to_back`
- 條件：`trust 10～12`、S09 選擇留下，且 `flags.s08_forced_walk != true`
- 畫面：停電或颱風夜，狗背對她睡在伸手可及處；牆上掛著鑰匙與牽繩
- Ch2：依賴從穩定開始，因此忙碌造成的裂痕會更痛，修復也更有重量
- 情緒：暖、輕、不催淚

### 結局 B｜選定但還在學

- 標籤：`ending_ch1_chosen_learning`
- 條件：`trust 4～9`、S09 選擇留下；或 `trust 10～12` 但 `s08_forced_walk = true`，因 A 被排除而回落至 B
- 畫面：狗敢睡近，但仍會睜眼確認；或背對一下，又轉身查看予安是否還在
- Ch2：標準主線；班表忙碌後，予安容易忘記切換語氣
- 情緒：最接近多數人的真實好結局

### 結局 C｜送走之後

- 標籤：`ending_ch1_handed_over`
- 條件：S09 選擇將狗交給同事，不受 trust 限制
- 畫面：咖啡廳門口，狗僵住或低鳴；她仍把牽繩交出去。公寓重新只剩冰箱嗡嗡
- 後續：不是 Game Over；可解鎖探視短尾，並寫入 `flags.gave_away = true`
- 高信任送走：可追加 `landmark_chose_reason_over_bond`
- 情緒：安靜、酸；敘事不可責罵玩家

### 結局 D｜薄冰同住

- 標籤：`ending_ch1_thin_ice`
- 條件：`trust ≤3`，但 S09 仍選擇留下
- 畫面：牽繩掛好了，狗卻睡在門邊。她說「晚上見」，狗沒有看她
- Ch2：先修復信任，再談互相依賴
- 情緒：誠實、微悶，但不是懲罰性壞結局

### 結局關係圖

```text
                    S09 留下？
                   /         \
                 是            否 →【C 送走】
                 |
           trust 區間
         /      |       \
      ≤3      4～9      10～12
       |        |          |
    【D 薄冰】【B 選定】【A 背靠】
          \      |      /
            皆可進 Ch2
```

## 5. 選擇設計口訣

1. 升信任：等、側身、回來、擋、輕、留門縫。
2. 降信任：快、兇、關、丟給別人、為面子硬撐。
3. 荷包與請假等風味選擇少動 trust，改動壓力或班表 flags。
4. 結局差異用狗的睡姿與距離表達，比結算數字更有力量。

### 5.1 台灣用語與敘事口吻（鎖定）

- 玩家可見文字一律使用**繁體中文、台灣用語**；禁簡體字與中國慣用語。
- 常用詞鎖定：`冷氣`（不用空調）、`影片`（不用視頻）、`資訊`（不用信息）、`品質`（不用質量）、`動態上貼照片`（不用曬照／曬貓）。
- **旁白**＝**第三人稱**。口吻：**帶點詼諧／乾幽默**，丟出好記的**事實與看法**（觀察銳利、一句到位）；不堆華麗比喻、不寫成謎語詩。情緒仍靠日常動作、距離與聲音承接，幽默是觀察的刀，不是耍寶。
- **對白**（予安）維持短、乾、劃界；**心裡話**短、內斂，不必強塞幽默。
- 予安像 26 歲台灣上班族：對外禮貌簡短，獨處時低聲、稍微笨拙；避免翻譯腔、八點檔哭喊與說教。
- 低信任路線仍保持同理，不用旁白責罵玩家；負向選項描寫行為與後果，不貼「壞人」標籤。
- 程式落地後須執行 `python Renpy_game/tools/validate-s01.py`，確認簡體字／中國用語掃描通過。

### 5.2 章節選擇摘要

- 章節標題下方只放**該 Section 的故事大綱**，用一至兩句交代核心事件與情緒。
- 禁止放跳段預設狀態、flags、trust、測試方式、操作說明或「從某狀態開始」等系統文字。
- 摘要不提前揭露選項結果與後續分支；應讓玩家知道「這段故事在說什麼」，而不是「遊戲如何載入這段」。
- S01～S10 的鎖定摘要見 `outline_trilogy_ch1_10sections.md` 各 Section 的「章節選擇摘要」。
