## 痛點 1️⃣ 隱藏內容發現機制不夠明確

### 問題分析

**現況**：
- 玩家完成四個結局後，隱藏內容（狗日記、職場反思、朋友視角）自動解鎖
- 但結局畫面沒有明確提示「新內容已解鎖」
- 新玩家可能認為「遊戲結束」就關閉遊戲，遺漏隱藏內容
- 導致：玩家無法體驗設計好的層次化敘事，影響滿足度與重玩動機

**影響範圍**：
- ❌ gamer_30：可能遺漏四結局 × 隱藏內容的全景，重玩價值打折
- ❌ gamer_25_female：無法發現「被看見的層次」（朋友視角等），社群分享素材不足
- ❌ gamer_60_retired：不知道如何解鎖隱藏內容，長期黏著度下降

### 執行方案

#### **Phase 1: 結局畫面優化（Ren'Py 實裝）**

**時序**：結局動畫播放完畢 → 3～5 秒後觸發

```python
# script.rpy 中 ending_a/b/c/d label 後添加

after_ending_unlock:
    # 3秒停留讓玩家讀完結局最後一句
    pause 3.0
    
    # 顯示解鎖提示彩帶效果
    show screen unlock_notification(
        icon="unlock",
        content_names=get_unlocked_content(ch1_ending)  # 動態取得解鎖內容
    )
    pause 2.5
    
    # 淡出結局畫面，回到選單提示
    show screen post_ending_menu
    pause
```
