# Section 02｜後門那一瞥

> Ch1 Trust · 第三人稱敘事稿  
> 閱讀約**七分鐘**｜無意間相遇：不是認養，是沒能假裝沒看見  
> **開場鉤子：** 與 S01 合計 **≤15 分鐘**內，玩家須感到「想留下這隻狗」

**設計對齊（`game_guild.md` §0）**

| 項目 | 本段設定 |
|------|----------|
| 定位 | **相遇段**（S02）；進段 `trust = 0`；**15 分鐘退款線收束段** |
| 信任變動 | 升：蹲下等、不硬抓、願意暫時照顧（**0～+2**）；降：趕、硬抓、冷漠離開（**−1**） |
| 主軸 | **距離 Dist**；畫面**不顯示數字**，靠狗退／停／半步表達 |
| 選擇 | **1 組信任**（蹲等／硬抓／趕走）＋**1 組路徑**（動保／急診／大門）；信任組必須**立刻可感**（pose／距離／內心一句） |
| 軟分軌 | S01 `peeked_backdoor` → 開場「早有預感」；否則措手不及 |
| 收束 | 電梯上樓、「今晚不算數」→ 玩家想進 S03 |
| 演出四拍 | **進場畫面**（後門遠距）→ **關鍵動作**（蹲等／硬抓／趕走）→ **反應鏡頭**（蹲等：先靠近保持距→飯盒更近→水後退→解釋再靠前；再半步測試）→ **路徑選項**（下一步）→ **離場鉤子** |
| BGM | `melancholy` → 蹲等或良心回頭切 `tender` → 抱走後 `warm`；硬抓路線維持 `melancholy` 至離場前 |
| 距離回聲 | `dist_ok`：`far`→`mid`→抱時`near`；良心回頭以 `s02_conscience_return` 維持 `mid` 外緣；硬抓多停在 `far`／抱時才到 `mid` |

---

週五傍晚。予安還是最後一批關螢幕的人。簡報交出去了，身體卻像還欠一份存檔。耳機掛在脖子上，這次沒開白噪音——外面有真的風。

便利商店門一開，店員揚了揚下巴：

「小姐，小7 還在。」說得很快，像怕自己太關心。「後門那隻。店長說動保明天才排得到。你要是……算了，當我沒說。」

予安「喔」了一聲。比昨晚短半拍。

她提便當到巷口。轉角在左邊——兩年來從不轉進去的那個轉角。

若昨晚繞過去看一眼，腳步會比較穩，像赴一個沒說出口的約。若沒有，轉角會突然變得很近，近得像地板自己往前送了一步。

她轉進去了。

卸貨區比想像窄。機車棚陰影把地面切成深淺。垃圾桶邊壓扁的紙箱翹著邊角。氣味是濕紙箱混隔夜油，還有一點點體溫味，淡到幾乎像錯覺。

**身世半隱（MEMORY §4.1／§4.2）：** 牠身上殘一點洗衣粉混舊衣的味道——淡、短；像曾靠近過某個人，後來那個人沒再回來。**不定罪、不講前主人故事。**（勿寫「沒有前任／無項圈＝無過去」——與鎖定衝突。）

然後她看見了。

不是那種擺出來給人看的棄養。沒有綁絲帶、沒有紙條、沒有「請好心人收留」。一隻瘦的混種幼犬趴在紙箱邊——**Option B｜wiry**：毛質略硬亂（scruffy／wiry），厚筆觸 impasto；毛色偏蜂蜜褐，耳尖較深，背脊有深色 grizzle，胸口／吻周一塊奶油淺蜜；短腿、偏瘦幼犬；大而暖的深褐眼。（產圖對齊 `image_dog.md`／`dog-ref-canonical.png`／`assets/dog/refs/`。）

予安停在兩步外。**手指動了半寸又縮回**——主人陰影半隱（MEMORY §3.1）：怕靠近之後有人離開；**不開車禍閃回。**

狗的鼻子動了。便當袋、鞋底、她垂在身側的手指。怕，但餓勝過怕。眼睛圓、深褐、亮得不太公平——在這種地方，不該有這麼亮的東西。

她先眨眼。

狗先看開。

那半秒裡，世界很安靜。安靜到她聽見自己吞口水的聲音。

> ▷ **信任選擇（距離 Dist）— 本段唯一動 trust 的選項組**  
> **A｜蹲下，側身等待**（不伸手）→ 狗退半步後會停；Dist＋／`trust +1`；內心：「我可以什麼都不做。」  
> **B｜直接伸手抱／抓** → 狗僵住、短促嗚聲；Dist−／`trust −1`；仍可帶走，質地更脆  
> **C｜拍腿趕開，轉身就走** → 狗縮回紙箱；Dist−／`trust −1`；可接「良心回頭」變體（`trust 0`）

予安把便當袋放到地上，慢慢蹲下。膝蓋輕響一聲。她側著身，讓自己看起來小一點——手機上看過的說法，此刻願意試。

狗往後縮半步，屁股碰紙箱，沙沙響。

她沒追。

「嚇到了嗎。」開會時那種尖銳的語氣收不回來，獨處時放軟的低聲還不熟，擠出來只有這一句。

狗不回答。鼻子再伸出來一點，嗅便當。她掀開蓋子，用筷子挑出一點白飯，放在掌心外的地上——離自己遠，離狗近。手收回來，掌心朝上，停在空氣裡。

狗靠近。停。再靠近。舌尖點了一下米粒，又點一下。每吞一口就抬眼看她。

她很想摸頭。手指癢。她把癢吞回去。

「動保明天才來。」她對狗說，也對自己說。「明天。」

明天兩個字在巷子裡彈了一下，就消了。

狗吃完那一小撮飯，沒有衝過來。往前半步，停在「既不碰你、也不放你走」的距離。尾巴不搖，輕貼腿側，像還在開會表決。

予安站起來。往後退一步——測試。若蹲等成立，狗跟著往前半步，再退則不再跟，只盯腳踝。若硬抓／趕走質地，狗可能不跟，只壓低下巴盯鞋尖。

原來「離開」也是靠近的反面練習。

店員從騎樓探頭：「小姐？要不要我幫你打給——」

「我知道了。」語氣比較低、比較慢。不是客服音，像對自己下指令。「我……先處理。」

> ▷ **路徑選擇（風味為主；少動 trust）**  
> **1｜留地址，等動保明天** → `flags.called_shelter = true`  
> **2｜先帶夜間急診** → `flags.vet_first = true`（荷包↑；若抱時溫柔可 `trust +1`）  
> **3｜只帶到公寓大門過一夜** → `flags.gate_night = true`（主推 S03；搭配蹲等 → 結算可 `trust +2`）

予安看著那隻狗。狗看著便當袋，又看她的臉，最後看向巷口——車燈一掃而過，像有人用很大的手在翻書。

她聽見自己說：「今晚不算數。」

聲音輕得像怕被巷子聽見。

她把空便當盒收進袋子，留一點水在瓶蓋裡推過去。狗嗅了嗅，喝了兩口。水聲很小，小到她忽然覺得胸口某處鬆了一下——不是整個人鬆下來，只是「至少今晚牠還喝得動」那種小小的鬆一口氣。

**這一刻玩家應感到：不想就這樣把牠留在這裡。**

「我抱你一下。」她事先預告，像對同事預告會議延遲。「只是抱。很快。」

她沒從正面撲。側身，手臂穿過胸腹下方，用力平均，像搬一份怕散的文件。狗僵住，短促嗚了一聲，爪子在她袖口抓出淺痕。她痛得吸氣，卻沒鬆手，也沒罵。

「抱歉。」低聲說。第一次，低聲聽起來比較像她自己。「我也不會。我們……先離開這裡。」

機車棚燈管閃了一下。紙箱空了。陰影少了一塊活的東西。

走向公寓的路上，狗的心臟隔著她的手臂跳得很快。她的心臟也是。兩個節奏疊在一起，亂，但沒有停下。

電梯門要關時，她用肩膀擋住。狗的鼻子埋進她外套褶裡，嗅加班、關東煮、與一點點害怕的味道。

予安低頭看牠。

「我叫予安。」然後覺得可笑——狗又不辦證件。「他們叫你小7……你要不要換一個，再說。」

門關上。樓層燈一格一格往上跳。

她沒有數。第一次，她忘了數。

## 設計註記（對齊 `game_guild.md`）

- **開場鉤子：** S01（約 5.5 分）＋ S02（約 7 分）≤ **15 分**；收束在「想留下」＝電梯上樓、兩顆心跳疊在一起。
- **信任：** 進段 0；淨變動 **0～+2／−1**。選 A 後須**立刻**看到狗停／吃／半步——勿只靠結算數字。
- **選項密度：** 2 組（信任＋路徑），符合 §0「每段最多 1 組動 trust」。
- **Dist 軸：** 退／半步／僵住＝畫面信任條；禁止跳出數字。
- **良心回頭：** 趕走後回頭寫入 `flags["s02_conscience_return"]`；反應鏡頭與喝水維持 `mid` 外緣，BGM 保留 `tender` 至抱走後切 `warm`，但 `dist_ok` 仍為 `false`，不取得溫柔照顧加成。
- **記憶點：** 她先眨眼，狗先看開；「既不碰你、也不放你走」的半步。
- **銜接 S03：** 「今晚不算數」→ 大門臨時國界；`vet_first` 改 S03 開場變體，主幹仍前進。

### 已實作 trust 結算

| 玩家行為組合 | 建議 |
|--------------|------|
| 蹲等＋不硬抓＋大門（溫柔抱） | `trust +2`，`dist_ok = true` |
| 蹲等＋暫時照顧，抱時過猛 | `trust +1` |
| 硬抓帶走 | `trust −1`，仍進 S03 |
| 趕走後良心回頭 | `trust 0` 或鋸齒 `−1` 後 `+1` |
