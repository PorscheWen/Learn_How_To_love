# Learn How to Love — Demo 設計文件

**篇章：** Chapter 1: First Steps（信任）  
**切片：** 接回家第 1–7 天  
**預估遊玩時間：** 35–45 分鐘  
**平台：** 瀏覽器（本機 `index.html`）  
**音樂：** Web Audio 程序化環境 BGM（無外部音檔）

### 時間軸說明

- **Day 1**：雨天相遇 + 第一夜（prologue，順序敘事）。
- **Day 2**（可玩）：早晨→廚房→午後聲響→入夜；伏筆 `day2CalmSound`、Memory《第一次自己吃》。
- **Day 3–7**（主線）：場景 `day` 欄位與 HUD `Day N` 一致。
- **Epilogue「七天」**：自相遇日（Day 1）起算第七天。

## 一、Demo 目標

1. 驗證「感受 + 羈絆 → 特別事件」核心循環是否動人。
2. 展示狗的感官視角（氣味提示、色溫、場景切換、無數字面板）。
3. 收集玩家意願：是否願意玩完整三部曲。
4. 產出可匯出的 Demo 存檔 JSON（供正式版跨作存檔原型）。

---

## 三、系統（Demo 版）

### 隱藏數值（玩家不可見）

| 數值 | Demo 範圍 | 說明 |
|------|-----------|------|
| Trust | 0–100 | 影響狗是否靠近、跟脚 |
| Bond | Lv1 → Lv2 | Demo 結束時達 Lv2 Familiar |
| Comfort | 固定高 | 第一部 Demo 不涉及疾病 |

### 可見：感受指示

- 耳型、尾型、場景色溫（暖＝安全，冷＝緊張）
- 氣味提示列（嗅覺 UI）
- 不顯示 +20 / Lv2 等數字

### 特別事件

| 事件 | 等級 | 觸發 |
|------|------|------|
| 尿墊之夜 | Memory | Day 3 選「不罵、清理、陪坐」 |
| 雷雨 | Memory | Day 6，Bond ≥ 進度且曾安撫 Anxious |
| 第一次跟脚 | Moment | Day 5 散步，Trust ≥ 50 |
| 靠膝 | Moment | 尿墊之夜後解鎖 |
| 你難過的那一天 | Moment | Day 7 主線 |

## 四、分支與後果（無 Game Over）

- 吼叫／忽略 → Trust 降、Hurt，Day 4 有修復窗口。
- 長期低 Trust → 《第一次跟脚》改為「遠遠跟著」版本，仍通關。
- 無 permadeath；壞選擇只改變事件台詞與 epilogue 相簿。

## 六、美術與基調

- 暖色低多邊形感背景（CSS gradient）
- 幼犬以 SVG 剪影 + 耳尾動畫表达情緒
- 基調：暖、有笑；催淚靠「第一次被留下」
