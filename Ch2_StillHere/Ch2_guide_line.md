## 三、主人背景揭露（Ch1 伏筆 → Ch2 說破）

> **原則：** Ch1 只暗示「怕被留下」；Ch2 **第一次**讓玩家知道完整緣由。  
> **基調：** 克制坦白，不灑狗血；**狗在場即可，不當治療道具**。

### 3.1 系列鎖定事實（撰寫時不可改）

| 項目 | 內容 |
|------|------|
| **事件** | 女主 **10 歲**那年，父母離異後**雙雙未帶她走**（不是一夜消失，是「兩邊都說下次再來接」然後沒有） |
| **當夜** | 在原本的家獨自過了一夜；隔天由**阿姨**接到外地生活 |
| **成長** | 阿姨疼她但不擅長說愛；她學會懂事、少要、**不敢先開口留人** |
| **Ch1 為何撿狗** | 仍是雨天衝動，**不是**計畫性收養；Ch2 才可說「後來才懂自己當時在找什麼」 |
| **與 Ch2 主線關係** | 童年「被留下」↔ 中年「學會留下來／卻忙到忽略狗」；狗是**唯一不變的成員** |
| **父母近況** | 多年幾乎無聯絡；Ch2 中後段 **父母一方生病／來電**（見 §3.4 觸發 C） |

**審查禁止：**

- ❌ 長段哭訴或指責父母的大独白  
- ❌ 對狗說「你就像當年的我」這類直白比附  
- ❌ 揭露後狗立刻「治癒」她（數值暴漲、特殊 pose 強制）  
- ❌ 用童年創傷當 Ch2 每場戲的解釋句  

### 3.2 揭露時機（三條主線，擇一為該周目 Landmark）

| 路線 | 建議 scene_id | 觸發 | 適合玩家 |
|------|---------------|------|----------|
| **A 整理舊物** | `ch2_backstory_attic` | Ch2 開場搬屋／收納；`ownerLingeringFear` 任意 | 喜歡靜默發現 |
| **B 對伴侶坦白** | `ch2_backstory_kitchen` | 伴侶問「你為什麼總怕門響」；需 Ch1 結尾 Bond ≥ 門檻 | Ch1 玩出信任感的玩家 |
| **C 父母來電** | `ch2_backstory_call` | `guide_line`「父母生病」支線；來電顯示久未聯絡的號碼 | 情感衝擊最強，需內容警告 UI |

**規則：**

- 每週目**只完整揭露一次**；設 `ownerBackstoryRevealed = true`（Landmark，鎖定）。  
- 未觸發路線可在 NG+ 或二周目以**相簿補述**帶過，不重複完整演出。  
- Ch1 `ownerLingeringFear` 高 → 揭露場 `sub` 加一句「你早就隱約知道是為什麼」；低 → 「原來是這樣」。

### 3.3 揭露段落草稿（供 `tw-narrative-voice` 潤飾）

以下為**場景包主幹**；落地時拆 `text`／`sub`，每段 1–3 句，打字機節奏宜緩。

---

#### 路線 A — `ch2_backstory_attic`（整理舊物）

**地點：** 新家的儲藏室／紙箱堆  
**狗：** `dog-home` 或 `dog-window`，在腳邊打盹，**不插話**  
**feeling：** Content（玩家）／狗 Sleepy  

**text：**

搬家最後一箱是阿姨寄來的。  
你本來只想快點封膠帶。  

紙箱角有一張摺小的學校聯絡單。  
十歲。  
空白欄位上，父親母親的電話，後來都換了人接。  

你不記得那是哪一次放學。  
只記得回家時燈沒開，鞋還在門邊，  
飯菜涼在桌上，像有人剛走。  

**sub：**

你沒有哭。  
十歲那年你也沒哭。  
你只是坐在客廳，等門鎖再響一次。  

**玩家選擇（不影響主線，影響相簿一句）：**

| 選項 | 相簿 `desc` 方向 |
|------|------------------|
| 把聯絡單夾進相簿，關上箱子 | 「有些過去，收起來，不是忘記。」 |
| 打給阿姨，只說一聲「我搬新家了」 | 「你終於先開口，打給會留下來的人。」 |
| 什麼都不做，去廚房煮飯 | 「你先照顧今天。過去等等也來得及。」 |

**揭露後系統：** `ownerBackstoryRevealed = true`；相簿 Memory `still_here_origin`。

---

#### 路線 B — `ch2_backstory_kitchen`（對伴侶坦白）

**地點：** 夜裡廚房，小夜燈  
**狗：** `dog-kitchen`，碗邊嗅聞後趴睡  
**觸發對白：** 伴侶（或同住家人）NPC 一句：「你每次有人出門，都會多站一下。」  

**text：**

${partnerLabel} 把熱牛奶放在流理台邊。  
沒有逼問，只是等。  

你開口前，先聽見自己的心跳——  
和 Ch1 那扇門關上時，很像。  

「我十歲那年，」你說，「爸媽沒有來接我。」  
不是吵架那晚。  
是後來好幾個禮拜，兩邊都說「下次」。  

最後一次，家裡真的只剩我一個人。  
阿姨來的時候，我還把鞋擺好，怕他們回來找不到。  

**sub：**

你以為早就過去了。  
可每次門響，身體還是會等。  

${dogLabel(s)} 在腳邊換了個姿勢，尾巴輕掃地板。  
你沒有對牠解釋。  
有些話，說給會回應的人聽就夠了。  

**伴侶回應（擇一 tier，依 Ch2 關係 Bond）：**

| tier | 回應方向 |
|------|----------|
| 高 | 「謝謝你告訴我。以後不用一個人等。」 |
| 中 | 「難怪你總提早回家。」（呼應 Ch1） |
| 低 | 沉默，遞紙巾——不評價 |

**揭露後：** 解鎖 Ch2 中期選項「請伴侶幫忙顧狗」；《被忽略的一週》修復線多一條。

---

#### 路線 C — `ch2_backstory_call`（父母來電）

**地點：** 客廳，手機螢幕亮著  
**前置：** Ch2 主線「父母生病」傳聞或醫院通知函  
**狗：** `dog-alert` → 玩家安撫後 `dog-attached`  

**text：**

陌生又熟悉的號碼。  
備註欄空白——你认得，這是母親的。  

電話響了三聲。  
${dogLabel(s)} 豎耳看你，不知道你在怕什麼。  

你接起來。  
對方嗓音變老，說住院、說想見你、說「那時候不得已」。  

你沒有立刻原諒，也沒有立刻掛斷。  
你只是走到窗邊，讓風吹進來一點。  

**sub：**

十歲那年的門，又在耳邊響了一次。  
這次是你握著手機，決定要不要開。  

**玩家選擇（有重量，寫入跨作）：**

| 選項 | 後果 | 跨作標記 |
|------|------|----------|
| 去醫院見一面 | Ch2 多兩場短場；情緒累積但**不強迫和解** | `visitedEstrangedParent` |
| 請阿姨代問狀況，自己不去 | 克制距離；相簿「我選擇保護現在的家」 | `keptDistanceFromParent` |
| 不接、封鎖號碼 | 允許憤怒；Ch3 epilogue 多一句「你沒有回頭」 | `refusedEstrangedParent` |

**text（選「去見一面」後，醫院走廊，短場）：**

消毒水味很重。  
母親比記憶中小一圈。  
她說「對不起」；你說「我知道了」。  

不是原諒。  
是你終於把十歲那個晚上，從喉嚨裡放下來一點。  

**揭露後：** `ownerBackstoryRevealed = true`；Ch3 氣味閃回可加入「醫院走廊」或「空屋夜」二選一（依上表 flag）。

### 3.4 揭露與 Ch2 主線的銜接

| Ch2 主線節點 | 揭露後的改寫 |
|--------------|--------------|
| 《被忽略的一週》 | `sub` 可選：「你忙到沒看見牠，像當年沒人看見十歲的你。」**僅一句**，不重複身世 |
| 《寶寶來了》 | 她怕「家又變空」→ 多一個選項「把狗納入寶寶介紹儀式」 |
| 《吵架之後》Landmark | 叼拖鞋；可選 `sub`「牠不會說下次再來」 |
| Ch2 結尾 | 狗在腳邊睡著；`sub`「這次，房間裡的人都在。」對照 Ch1 Epilogue |

### 3.5 揭露後的內心主軸轉換

| 階段 | 問句 |
|------|------|
| Ch1（已玩完） | 「我養得起這份責任嗎？」 |
| Ch2 揭露前 | 「我能不能不再等門響？」 |
| Ch2 揭露後 | 「我能不能**讓別人留下來**，也**看見還在的人**？」（狗／伴侶／孩子） |

## 五、內容警告（Steam 商店／遊戲內）

- 設定選單可預覽「劇情內容提示」  
- 路線 C 觸發前一次輕提示（非強制跳過，可「稍後再說」延後）
