# Prompt｜第三步：分天撰寫劇本（一次一天）

有了 `plot.md` 後，**不要一次寫完 7 天**。每天用下列範本（改天數與標題即可）。

**檔名規則：** 一律英文 `dayN_english_slug.md`（見 `week0/README.md`）。中文標題只寫在檔案內文。

---

請參考 `@Ch1_Trust_Version2/plot.md` 與 `@Ch1_Trust_Version2/00_core_settings.md`，撰寫「第 N 天：〈中文標題〉」的具體遊戲劇本，輸出到 `@Ch1_Trust_Version2/week0/dayN_english_slug.md`。

【撰寫要求】
1. 嚴格對齊 `plot.md` 該日的學習重點、**3～4 個分歧點**與信任結果。
2. 必須各含 **1** 個知識小遊戲（**剛好 5 題**）、**1** 個信任小遊戲（ID／題庫見 `04_minigames.md`）。
3. 格式使用電子小說劇本體：場景標頭、旁白、角色名、對話、動作提示、抉擇與分支結果。
4. 文筆：溫馨細膩、Show don't tell、台灣口語；多寫布丁的嗚嗚／縮團／後退等動作。
5. 選項寫成玩家「正在做」的動作句。
6. 只寫這一天，不要預寫隔天正文。
