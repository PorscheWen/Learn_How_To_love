## 0. 怎麼測

### 啟動

```
Ch1_Trust_Version2\Renpy_game\開啟遊戲.bat
```

### 存檔

| 項目 | 建議 |
|------|------|
| 解析度 | 至少測 **1280×720** 與 **1920×1080**（視窗／全螢幕各一次） |
| 顯示縮放 | Windows 縮放 100%／125% 各看一次字幕與立繪 |
| 存檔 | 各 Day 分歧前後各存一檔；讀檔確認 trust／flags |
| 章節 | 主選單 **選擇章節** → Day 1～7 皆可進 |

### 問題分級

| 級 | 定義 | 範例 |
|----|------|------|
| **P0** | 無法繼續玩／毀存檔／嚴重缺字滿屏 | Jump 斷裂、字幕全 X、小遊戲卡死 |
| **P1** | 體驗明顯壞掉 | 插圖嚴重重疊、背景時段錯、關鍵對白缺漏、上下文矛盾 |
| **P2** | 品質／polish | 語氣略硬、pose 不夠準、缺專用 bg（診所／街日）、BGM 切換突兀 |

[P?] 場景ID／畫面｜現象｜預期｜截圖或步驟｜建議轉交（文案／美術／引擎）

## 1. 文字缺漏與字型

### 1.1 必查

- [ ] 所有玩家可見字為**繁體中文、台灣用語**（禁簡體／大陆词：視頻→影片、質量→品質、信息→資訊）
- [ ] 無空白對白、無 `???`、無未替換 placeholder（`TODO`、`xxx`、`{dog}`）
- [ ] 省略號統一 `……`；少用 ASCII `...`
- [ ] 無 `牠 `／` 牠` 異常空格
- [ ] **SourceHanSansLite 缺字**：勿用 U+00B7 `·`（會變 X）→ 改 `｜`／`・`
- [ ] 選單／按鈕／小遊戲題目／解析／結算句都有字
- [ ] 知識 5 題：題幹、選項、解析齊全；過關／未過關都有小晴台詞
- [ ] 信任小遊戲：操作提示、成功／失敗旁白齊全

## 5. 是否重疊（插圖／UI）

Ren'Py 常見問題：`show dog`＋`show char`＋字幕層＋小遊戲 HUD。

### 5.1 立繪層

- [ ] 狗與人物**不嚴重糊成一團**（可並存但要讀得出主體）
- [ ] 狗／人物不被對話框切掉臉或關鍵動作（爪、鼻、眼睛）
- [ ] `hide dog`／換 pose 時無殘影雙狗
- [ ] zorder：背景 ＜ 立繪 ＜ 字幕／選項 ＜ 小遊戲 modal

### 5.2 UI 層

- [ ] 選項按鈕不擋關鍵插圖（或擋了但可接受且可點）
- [ ] 知識題／信任小遊戲開啟時，底層點擊不會誤觸劇情
- [ ] 滑鼠／鍵盤焦點清楚；不會點到透明死區

### 5.3 記錄方式

發現重疊時寫：

```text
[P1] d1_tg_space_feed｜狗與食盤／手指提示重疊｜預期狗在右側、提示在左下｜步驟：…｜交 visual-art／screens.rpy
```

## 6. Day1 手動路線表（最短完整通關）

建議至少跑 **2 條**：偏 B（給空間）＋偏 A（急／硬）。

### 6.1 路線 B（友善）

| # | 操作 | 預期畫面／文字 |
|---|------|----------------|
| 1 | 開場看到雨巷＋紙箱狗 | bg 滿版；`dog-box` |
| 2 | 分歧1 選整箱抱走 | trust 不降或微升 |
| 3 | 知識答 ≥4 | 過關台詞；可進清潔 |
| 4 | 分歧2 毛巾擦乾 | `dog-wet`；trust＋ |
| 5 | 信任小遊戲成功 | 開吃／距離近；`dog-hungry`→`shy` |
| 6 | 分歧3 後退給空間 | 不嚇跑 |
| 7 | 分歧4 陪客廳 | 夜客廳 bg；`dog-sleepy` |
| 8 | 日終 | 可結束或提示 Day2 |

### 6.2 路線 A（壓力）

| # | 操作 | 預期 |
|---|------|------|
| 1 | 分歧1 抓出箱 | 悲鳴／trust−；姿態更縮 |
| 2 | 知識故意答錯 | 仍可繼續；有「重看」感台詞 |
| 3 | 分歧2 想沖澡 | 尖叫→改擦；trust− |
| 4 | 信任小遊戲失敗（伸手） | 失敗旁白；可重試或延後 fed |
| 5 | 分歧3 摸頭 | `dog-scare` 或退縮 |
| 6 | 分歧4 回房關門 | 嗚嗚／距離遠 |

兩條都要能**走完且存讀正常**。

## 7. 對遊戲整體的建議（Steam 電子小說玩家視角）

> 參考標竿類型：*Life is Strange*／Telltale（選擇回聲）、*To the Moon*／*Spiritfarer*（情感節奏）、*Coffee Talk*（日常治癒）、日系 VN（快進／log／存檔）、寵物向敘事（狗是家人不是道具）。  
> 完整對照表見 [`agent/game-tester/steam-vn-players.md`](../agent/game-tester/steam-vn-players.md)。

### 7.1 玩家會立刻在意的點

| 面向 | Steam 玩家常說 | Version2 建議 |
|------|----------------|---------------|
| **開場 15 分鐘** | 決定退款或留下 | Day1 雨箱必須順、美、有「想留下這隻狗」；卡關／缺字＝直接差評 |
| **選擇有沒有差** | 「假選項」最毒 | A／B 要在旁白、pose、trust 上可感；日後 Day4／5 回聲更好 |
| **文字品質** | 繁中機翻／簡繁混＝差評 | 每章必跑繁中檢查＋口語像 26 歲上班族 |
| **小遊戲** | 像作業會被罵 | 知識 5 題要短；信任小遊戲失敗可重試、不死關 |
| **圖文一致** | pose／時段與台詞打架會出戲 | 對 `image.md`＋`image_bg.md`；紙箱禁鳥巢；夜戲用 night bg |
| **UI／滿版** | 黑邊、擋臉、重疊＝廉价感 | 背景滿版；字幕不切臉；立繪 zorder 固定 |
| **節奏** | 太慢煩、太趕沒感覺 | 旁白分段；心裡話短；可快進／略過打字機 |
| **基調誠實** | 宣傳治癒卻 jump scare 催淚 | Week0 走笨拙溫柔；不虐死、不道德綁架 |
| **收集感** | VN 玩家愛 CG／回想 | 之後可加相簿／landmark（紙箱雨夜、第一次給空間） |
| **時長價值** | 「太短不值」 | 7 天雙小遊戲；**Day1～7 可玩** |

### 7.2 體驗建議（產品向）

1. **Day1～7 可玩**（含章節跳關）；優先修時段 bg 與缺圖。  
2. **分歧後立刻給反饋**（旁白＋狗 pose），不要只改隱藏數值。  
3. **存檔點**：每個分歧前、小遊戲前後——符合 VN 玩家習慣。  
4. **歷史／Auto／快進**（若尚未有）：列入 Ren'Py UI backlog。  
5. **無障礙**：字級、對比、可關動畫；台灣玩家亦在意「能不能輕鬆讀完加班後的一夜」。  
6. **商店文案**（日後上架）：寫「學會照顧與被信任」，勿寫成養成數值刷刷樂。

### 7.3 測試通過門檻（Day1～7）

| 門檻 | 條件 |
|------|------|
| Smoke | 友善路線無 P0，可從 Day1 一路到 Day7 結局 |
| 可給朋友試 | Smoke＋無 P1 時段錯／重疊／缺字；章節可跳 Day1～7 |
| 章節就緒 | 可給朋友試＋flags／trust 抽樣正確＋結局三檔可感 |
