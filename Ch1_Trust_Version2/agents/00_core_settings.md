## 1. 作品定位

| 項目 | 內容 |
|------|------|
| 作品名 | 《一週的奇蹟：紙箱、女孩與毛球》 |
| 類型 | 療癒系電子小說（Visual Novel） |
| 時間軸 | 剛好 **7 天**（Week0＝相遇週） |
| 節奏弧 | 相遇 → 混亂 → 磨合 → 成長 → 建立羈絆 |
| 語言 | 繁體中文、台灣日常口語；禁歐化中文、禁機械翻譯腔 |

---

## 2. 角色設定

### 小晴（女主角）

- 26 歲都市上班族
- 生活節奏快、工作壓力大、內心孤獨
- **從未養過寵物**，完全不會照顧狗
- 行為基調：疲憊、笨拙、願意學、不敢隨便碰別人的界線
- 對白口吻：短句、口語、有時自言自語；不說教、不華麗

### 布丁（幼犬）

- 約 2 個月大
- 雨天路邊紙箱被撿到
- 前期：警戒、易受驚、縮成一團、嗚嗚聲多於吠叫
- 不會說話；情緒用動作、眼神、聲音傳達
- 信任度由玩家抉擇累積（見遊戲機制）

---

## 3. 故事核心

在短短一週內，兩人從陌生與混亂（小晴手忙腳亂學照顧、布丁戒備），到互相學習信任與陪伴。  
重點不是「立刻會養」，而是「從不會到願意學、從害怕到敢靠近」。

---

## 4. 遊戲機制

- **每天＝一個章節**
- 每章 **3～4 個劇情分歧點**，影響「信任度」（Trust）與 flags
- 每章固定各 **1** 個小遊戲（詳見 `04_minigames.md`／`plot.md`）：
  - **學習狗狗知識** `minigame: knowledge` — **每天 5 題**；答對 ≥4 過關加 `knowledge_score`，5／5 可再 `trust +1`
  - **增加信任** `minigame: trust` — 與布丁的距離／時機互動，直接加減 `trust`
- 信任度單次變化建議：`−2`～`+2`；Day7 正式收養建議門檻 `trust ≥ 6`（含小遊戲）
- 選項分級概念：
  - **A**：急著安撫／強制接觸 → 常降信任
  - **B**：給空間／用食物／用聲音 → 常升信任
  - （可選 C）：風味選，不改大結局，只改當日細節

### 狀態變數（寫劇本時可標註）

| 變數 | 說明 |
|------|------|
| `trust` | 信任度（整數） |
| `knowledge_score` | 知識小遊戲累積（理想一天 +1） |
| `flags.bathed` | 是否已嘗試清潔／擦乾 |
| `flags.fed` | 是否已成功餵食 |
| `flags.named` | 是否已取名「布丁」（Day1 末或 Day2 初） |
| `flags.adopted` | Day7 是否正式決定收養 |
| `minigame_clear.*` | 當日知識／信任小遊戲是否過關 |

---

## 5. 文筆風格（鎖定）

- 溫馨、細膩；**Show, don't tell**
- 多用細節與動作：雨、紙箱、發抖、嗚嗚、縮爪、後退半步
- 禁主題總結句（「她終於學會了愛」這類）
- 禁贅字堆疊：「當……的時候」「被……所……」能刪就刪
- 人對狗說話：短、輕、笨拙（道歉／試探／承認不會）

### 即時修正口令（潤稿用）

1. 「這段對話太生硬了，請改成一個 26 歲疲憊上班族女生會說的日常口語。」
2. 「請多加一點狗狗發出『嗚嗚聲』、搖尾巴或縮成一團的細部動作描寫，讓畫面感更強。」
3. 「去掉多餘的贅字（如：當...的時候、被...），讓文字更符合中文小說的閱讀流暢感。」
