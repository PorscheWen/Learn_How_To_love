# LHTL 繁體敘事語氣（台灣）

## 核心規範（必守）

**字體都用繁體中文，並且使用親切、溫柔、多情感的口吻和台灣人的字彙。**

適用所有玩家可見文字：`Demo/js/scenes.js`、`choice-reactions.js`、`story-agent.js`、`minigame-reactions.js`、`systems.js`（行為／相簿）、`game.js`（小遊戲 UI）、`index.html` 說明。

與 [`story-narrative`](../story-narrative/SKILL.md) 搭配：故事架構看 guide_line；**字詞與語氣以本 skill 為準**。

## 語氣三原則

1. **親切**：像對熟悉的人說話，不訓斥、不說教；店員可稱「阿姨／大姐」，語氣放輕。
2. **溫柔**：多用「輕輕、慢慢、一點點、還好、先」；避免命令句與冷硬結論。
3. **多情感**：寫「心裡」—慌、鬆、難為情、捨不得、慶幸；用感官（雨聲、空碗聲、風鈴）襯情緒，不只交代事件。

## 繁體與台灣用語

- **一律繁體**；禁止簡體字與簡體詞（如：塑料、打扰、信息、怎么）。
- **優先台灣說法**；詳表見 [reference.md](reference.md)。
- 指涉狗一律用 **「牠」**；未取名前用 `dogLabel(s)`，勿硬塞名字。
- 避免大陸網路梗、過度書面公文腔、英文術語（`deadline` → 交件期限、`routine` → 日常節奏）。

## 句式與節奏

- 短句＋換行留白；副文本 `sub` 比主文本更慢、更像心裡話。
- 對白用「」；口語可帶「喔、啊、耶、嘛」但節制，不每句都加。
- 選項文案：玩家第一人稱、具體動作（「深吸一口氣——得請假出去買」），勿抽象標籤。
- Demo 預設文字速度「緩」：Day 2 店舖線可設 `textMult` / `breathMs`，勿寫過長單段。
- **打字機淡入（§6.5）**：每段以 **1–3 句**為宜；換段前留空白行讓淡入有呼吸感；避免一段超過 60 字的連續文本。

## 動態日記文案（§6.5）

日記條目由 `story-narrative` 觸發，由本 skill 潤飾文字：

- **長度**：2–4 句，簡短如標題式詩句或素樸散文。
- **視角**：可用「你」的回顧視角或第三人稱旁白；帶有「那天」「那一次」等時間錨。
- **語氣**：比正文更輕、更私密，像在日記本裡寫給自己的備忘。
- **禁止**：數值語言（Trust ↑）、說明文字（「這個事件代表……」）、過度煽情。

**示例（尿墊之夜 Moment）：**
> 那個晚上，你沒有罵牠。  
> 只是蹲下來，把濕掉的墊子換掉，然後陪牠坐在旁邊。  
> 牠抬頭看你一眼，縮進了你的影子裡。

## 工作流程

### 撰寫新文案

1. 確認場景情緒（Feelings）與狗視角／人視角。
2. 起草：主文（發生什麼）→ 副文（心裡話）→ 選項（溫柔的具體行動）。
3. 對照 [reference.md](reference.md) 替換禁用詞。
4. 念出來：是否像台灣人會說的話？是否夠暖、夠細？

### 修改／審查既有文案

1. 跑繁簡修正（若改 Demo）：
   ```bash
   node Demo/tools/tw-locale-pass.js
   ```
2. 搜尋殘留簡體：`塑料|打扰|信息|怎么|看见|跟着|写的|轻轻`
3. 檢查 choice key 與 `scenes.js` 選項文字完全一致。

## 好／壞示例

| ❌ 避免 | ✅ 建議 |
|--------|--------|
| 請假不體面，但必要。 | 請假這件事，說出口才發現有點難為情。但空碗不會等你開完會。 |
| 這不是浪漫，是需要負責的開始。 | 心裡忽然一緊。養牠，不只是帶回家那麼浪漫——你得先讓這個小傢伙有東西可以填飽肚子。 |
| 店員：「全對。」 | 店員：「全對耶。幼犬第一天就能吃到該吃的。」 |
| 像記一張會考試的清單。 | 像記一張明天就要交的小考題目。 |
| 你还在吗？ | 你還在嗎？ |

## 交付檢查清單

- [ ] 全文繁體，無簡體字
- [ ] 用語符合台灣習慣（reference 對照）
- [ ] 語氣親切、溫柔，有明確情感（不只資訊）
- [ ] 選項 key 與 scenes 一致
- [ ] 未取名前不用固定狗名；已取名後可自然念名字
- [ ] 無遊戲化數值語（+20 Trust 等）
- [ ] 每段不超過 3 句（打字機淡入節奏）
- [ ] 日記條目（若有）：2–4 句，私密語氣，無說明文字
