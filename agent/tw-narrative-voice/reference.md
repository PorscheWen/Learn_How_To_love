# 台灣繁體敘事 — 用語對照與詞彙表

## 必換（簡體／大陸 → 台灣繁體）

| 避免 | 改用 |
|------|------|
| 塑料 | 塑膠 |
| 信息 | 訊息 |
| 打扰 / 轻轻 / 写的 / 看见 / 跟着 / 跟脚 | 打擾 / 輕輕 / 寫的 / 看見 / 跟著 / 跟腳 |
| 还在 / 你会 / 你在吗 | 還在 / 你會 / 你還在嗎 |
| 考试 / 便条 / 安顿 | 考試 / 便條 / 安頓 |
| deadline | 交件期限 |
| routine（日常） | 日常節奏 |
| 软件 / 视频 / 质量 | 軟體 / 影片 / 品質 |
| 老板（職場） | 主管／老闆（依語境） |
| 够（簡體） | 夠 |
| 这里（簡體） | 這裡 |

## 台灣口語偏好

| 情境 | 建議 |
|------|------|
| 請假 | 請假、傳訊息給主管、跟主管說 |
| 寵物店店員 | 阿姨、大姐；「對啦」「這個不行喔」「交給阿姨」 |
| 主管回覆 | 「好，先顧家。」（比「照顧好」更口語） |
| 程度 | 有一點、還好、蠻、虛虛的、心裡鬆了一點 |
| 小東西 | 小傢伙、小秘密、小考題目 |
| 否定 | 別急、沒關係、第一次都會亂 |

## 情感詞庫（可多運用）

**人的**：難為情、慌、虛、捨不得、慶幸、心裡一緊、鬆了一點、眼裡還有睏意  
**狗的**：縮、探頭、豎耳朵、輕輕嗅、尾巴夾緊、呼吸同步、沒有叫  
**環境**：雨聲、空碗聲、風鈴、塑膠味、木屑、咖啡味  

## 語氣禁止

- 訓話：「你應該」「必須立刻」
- 冷硬：「失敗」「錯誤」「不合格」→ 改「還在試」「差一點」「再想想」
- 廉價催淚：彩虹橋、天使、毛孩（系列 guide_line 亦忌）
- 遊戲術語外露：Trust、Bond、數值、tier

## 標點與格式

- 中文引號：「」
- 破折號：——（情緒停頓）
- 省略號：……（思緒、留白）
- 英文 Day N 可保留；其餘 UI 用繁體

## 範例段落（Day 2 寵物店）

```
店員是個戴圍裙的大姐，
看見你空手進來、一臉慌，就笑了：
「第一次養？昨天帶回家的？」

你點頭，心裡還是虛虛的。

她指著貨架，語氣放輕：
「幼犬啊，不是買最貴的——
是買對的。」
```

副文：
```
貨架上什麼都有。
你得在這裡，
替牠挑對第一套「家」的東西——
心裡還慌，但總算有人可以問。
```
