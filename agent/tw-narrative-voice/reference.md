## Day 1 詞彙與範例場景

### 主敘事 `text` 摘錄（語感參照）

**相遇（prologue_rain）**
```
傍晚，雨沒有要停的樣子。
巷口那個溼透的紙箱輕輕動了一下......
你蹲下去，對上一雙濕漉漉、還在發抖的眼睛。

牠很小，毛貼著骨頭，像一整團被雨打溼的暖色。
你想用自己的外套先裹住牠

牠沒有叫，只是很膽怯、很慢地靠過來。
彷彿只能相信眼前這個人
```

**回家／狼狽（prologue_home）**
```
進門後，房門關上的瞬間，才發現牠從頭到腳都在滴水...
毛巾、吹風機、溫水，你腦子裡亂成一團。

將牠從箱子抱出來，卻蜷縮在箱子旁邊，
小爪子上的水痕，在地板上印出一個可愛的愛心。
```

**浴室（prologue_dry）**
```
浴室鏡子蒙了一層霧。

你一手按住牠，一手舉吹風機...
牠一驚，掙了一下，毛巾滑到地上。
你差點踩到，心跳快了一拍。

「對不起、對不起……」
你說得比平時更輕，
像在跟一個也嚇壞了的小生命道歉。
```

**夜裡（prologue_night）**
```
折騰完，牠縮在紙箱邊。
毛還有一點濕，但至少不再滴水。

你開了小夜燈，在三步之外坐下——
不靠近，也不離開。
已經半夜，但你仍不敢入睡。

嗚嗚咽咽的哀鳴，從客廳傳來
一聲、停一下、又一聲——
像把「怕」從喉嚨裡一點一點擠出來。
```

**天亮（prologue_dawn）**
```
天快亮時，哀鳴終於慢慢停了。

牠趴在紙箱邊，呼吸淺淺的，
像耗盡了所有力氣。

你也一夜未眠
但看見牠還在，心裡還是放鬆了一點。
```

### 副文 `sub` 摘錄

| 場景 | 副文 |
|------|------|
| prologue_rain | Day 1，你擔憂地先帶牠回家。／那時候，你們都還不知道，這叫作「開始」。 |
| prologue_home | 第一夜才剛開始。／你還不知道該先做哪一步，心裡有點慌...／但你知道，不能讓牠就這樣濕著過夜。 |
| prologue_dry | 沒有學習過，如何對待小生命。／你只能一邊試，一邊怕弄疼牠。 |

| prologue_dawn | 第一夜過去了。／你們誰彼此都很陌生，／但還是一起陪伴到了天亮。 |

### Day 1 選項摘錄

```
包住濕淋淋的紙箱，上計程車
深吸一口氣，手忙腳亂找毛巾和吹風機
吹風機調到低檔，先讓牠聞聞風
一手按穩、一手吹，越弄越亂也沒停
放棄吹風機，只用毛巾慢慢擦到半乾
走到三步外，輕聲說：「我在這，別害怕。」
開小夜燈，坐在地上，不強抱，等聲音慢下來
困得發煩，還是壓低聲音陪在遠處
撐到天亮……
```

**選項寫法要點（自 Day 1 歸納）：**
- 一個完整動作，不要兩個抽象詞（❌「安撫牠的情緒」）
- 可承認狀態：困得發煩、手忙腳亂、越弄越亂也沒停
- 帶引號時要短、像真的會開口說的話

## 情感詞庫（延伸 Day 1）

**人的：** 難為情、慌、擔憂、虛、捨不得、慶幸、心裡一緊、鬆了一點、眼皮下墜、一夜未眠  
**狗的：** 縮、探頭、豎耳朵、輕輕嗅、尾巴夾緊、呼吸同步、沒有叫、膽怯、靠過來  
**環境：** 雨聲、空碗聲、風鈴、塑膠味、木屑、咖啡味、霧、滴水聲  

## 語氣禁止（與 Day 1 基調相反）

- 訓話：「你應該」「必須立刻」「要讓牠知道誰是主人」
- 冷硬：「失敗」「錯誤」「不合格」→ 改「還在試」「差一點」「越弄越亂也沒停」
- 標籤式形容狗：「這隻狗很害怕」→ 改「還在發抖的眼睛」「把臉藏起來」
- 廉價催淚：彩虹橋、天使、毛孩
- 遊戲術語外露：Trust、Bond、數值、tier

## 標點與格式

- 中文引號：「」
- 破折號：——（距離、停頓，如「三步之外坐下——」）
- 省略號：`……` 或 `...`（思緒、雨聲未盡；全稿擇一風格並統一）
- 英文 Day N 可保留；其餘 UI 用繁體
- 換行：主文用 `\n\n` 做段落呼吸；副文可一句一行

## 範例段落（Day 2 寵物店 · 延續 Day 1 語感）

```
店員是個戴圍裙的大姐，
看見你空手進來、一臉慌，就笑了：
「第一次養？昨天帶回家的？」

你點頭，心裡還是虛虛的。

她指著貨架，語氣放輕：
「幼犬啊，不是買最貴的——
是買對的。」
```

副文：
```
貨架上什麼都有。
你得在這裡，
替牠挑對第一套「家」的東西——
心裡還慌，但總算有人可以問。
```
