# Steam 電子小說市場：敘事熱賣與避雷（設計視角）

> 供 **story-narrative** 撰寫章節大綱、分支、商店文案、審查劇情時對照。  
> 本文件從**敘事設計師**角度分析 Steam 熱門作品**為何賣**、**為何翻車**，以及 LHTL 該強化／該避開的劇情決策。  
> 上架門檻見 [`steam-release.md`](steam-release.md)；玩家驗收見 [`game-tester/steam-vn-players.md`](../game-tester/steam-vn-players.md)。

## 1. 敘事設計師視角：熱賣 vs 翻車

| | **熱賣敘事遊戲** | **翻車／退款多** |
|---|------------------|------------------|
| **開場** | 15 分鐘內建立「這個故事值得我」 | 慢熱無 hook、或開場就硬催淚 |
| **承諾** | 商店寫什麼，劇情就給什麼 | 標籤／文案與實際基調不符 |
| **選擇** | 少而精，有回聲、有記憶 | 假選項、結局收束成一條 |
| **節奏** | 笑／暖／靜／重有起伏 | 灌水對白、小遊戲打斷閱讀 |
| **差異化** | 一句話說得出「只有這款有」 | 像某某作的劣質仿作 |
| **時長** | 付費章 **>2h** 且每段有功能 | <2h 通關、重複場景湊數 |
| **重玩** | 分支／相簿／Landmark 有收集動機 | 二周目零差異 |

## 2. Steam 熱門標竿：熱賣原因（敘事面）

以下為**敘事架構**可借鑑之處；不要求 LHTL 複製玩法或題材。

### 2.1 *To the Moon*／*Finding Paradise*（Freebird Games）

| 熱賣原因 | 敘事手法 |
|----------|----------|
| 口碑傳播 | **倒敘＋拼圖式揭露**；眼淚來自「終於懂了」而非突然死亡 |
| 時長合理 | 4–6h 單作，每段都有新資訊 |
| 音畫同頻 | 像素＋鋼琴；場景轉換服務情緒 |

**LHTL 借鑑：** 跨三章 **伏筆回收**（Ch1 Landmark → Ch3 閃回）；Ch1 **不揭底**；Memory／相簿像「拼圖碎片」。  
**勿抄：** 勿做成純 linear kinetic；LHTL 賣 **選擇與關係變體**。

### 2.2 *Life is Strange*（Dontnod）

| 熱賣原因 | 敘事手法 |
|----------|----------|
| 代入感 | 具體日常（宿舍、走廊、音樂）＋**選項像真人在猶豫** |
| 選擇話題性 | 少數關鍵選擇被記住、討論、二創 |
| 角色弧 | 主角與配角都有可見變化 |

**LHTL 借鑑：** 選項用**第一人稱具體動作**（「蹲下來擦地」非「溫柔處理」）；尿墊／雷雨等 **可被記住的節點**；`choice-reactions` 必寫。  
**勿抄：** 勿超自然懸疑；LHTL 賣 **真實養狗日常**。

### 2.3 *Spiritfarer*

| 熱賣原因 | 敘事手法 |
|----------|----------|
| 準備即愛 | 「送別前的一起生活」比死亡本身更催淚 |
| 收集感 | 每個 NPC／任務是一格記憶 |
| 基調誠實 | 治癒但不否認告別 |

**LHTL 借鑑：** Ch1–2 寫 **一起過日子的細節**；相簿 `title`／`desc` 是 **情感里程碑**；Ch3 告別前 Ch2 **靜日常** 必須厚實。  
**勿抄：** 勿變成經營 sim；互動服務 **閱讀節奏**。

### 2.4 *Coffee Talk*／*VA-11 Hall-A*

| 熱賣原因 | 敘事手法 |
|----------|----------|
| 低壓力 |  vignette 結構；一場一個情緒 |
| 口語 | 對白像聊天，不像論文 |
| 氛圍 | 重複場景（酒吧）但**每夜對話不同** |

**LHTL 借鑑：** Ch2 **被忽略的日常** 用 vignette；`breathMs` 空檔；**smell** 分層當氛圍；tw-narrative-voice 口語化。  
**勿抄：** 勿全章只有室內一景；LHTL 有 **班表與外出**。

### 2.5 *Steins;Gate*／*Clannad*（日系 VN）

| 熱賣原因 | 敘事手法 |
|----------|----------|
| 長線 payoff | 前半鋪墊，後半爆發；玩家願意重玩 |
| 路線表 | 多結局有 **條件透明感**（社群攻略） |
| 角色路線 | 副線不改主世界邏輯 |

**LHTL 借鑑：** 三部曲＝**超長路線表**；每章 ≥3 結局 + Landmark ≥3；副線 **變體** 不 contradict 主線。  
**勿抄：** 勿戀愛 route 競爭；LHTL 只有 **你與這隻狗**。

### 2.6 *The Walking Dead*（Telltale）

| 熱賣原因 | 敘事手法 |
|----------|----------|
| 選擇重量感 | 「XXX will remember that」——玩家**感到被記住** |
| 失敗可敘事 | 關係破裂仍可玩，不是 Game Over |

**LHTL 借鑑：** Landmark **鎖定** + epilogue **呼應**；吼叫線 → `day4_repair`；**無 permadeath**。  
**勿抄：** 勿每選都假裝重大；LHTL 重大選 **少而真**。

### 2.7 犬類／告別向（*Farewell North*、*My Little Puppy*、*The Last Night of Cheryl*）

| 熱賣原因 | 常見翻車 |
|----------|----------|
| 真實生命週期、互動 | 只有 30 分鐘彩虹橋、或永遠幼犬 |
| 狗是主角／媒介 | 狗只是背景裝飾 |
| 基調一致 | 商店寫 cute 進 game 卻虐殺 |

**LHTL 借鑑：** **幼→中→老** 三部曲；狗 **感官 POV**；Ch1 不賣死亡（guide_line §二）。  
**勿抄：** 勿 Ch1 就寫安樂；勿 *Domestic Dog* 式 permadeath。

### 2.8 *Doki Doki Literature Club!*（反例教學）

| 教訓 | 對 LHTL |
|------|---------|
| **標籤誠實** 也能爆紅 | 副標／長描述寫清 Ch1 基調 vs Ch3 內容警告 |
| 顛覆需鋪墊 | LHTL 不玩 meta 嚇人；但 **基調轉換**（Ch1→3）須在文案預告 |

## 3. 敘事設計應避免的因素（差評／退款根源）

撰寫或審查大綱時，下列項 **一項即 P1 敘事缺陷**：

### 3.1 結構與分支

| 避免 | 後果 | LHTL 對策 |
|------|------|-------------|
| **假選項**（三選一結果相同） | 「選了沒差」差評 | 每個 `choices` 至少改 reaction／flag／下一場 |
| **結局收束成一條** | 重玩無意義 | 每章 ≥3 收束 + 條件表 |
| **Landmark 可 S/L 洗掉** | 選擇無重量 | 觸發後鎖定、寫入跨作 |
| **低 Trust ＝ 死局** | permadeath 變相 | 變體 epilogue + repair 線 |
| **灌水場景**（無 Memory／笑暖／推進） | 「拖時間 refund」 | 全章總覽表每段有 **主題句 + 必達事件** |

### 3.2 基調與承諾

| 避免 | 後果 | LHTL 禁則 |
|------|------|-----------|
| **Ch1 彩虹橋／死亡開場** | cheap 催淚、退款 | 死亡僅 Ch3 |
| **全程催淚 sim** | 與商店「暖」不符 | Ch1 暖有笑、Ch2 靜 |
| **道德綁架安樂** | 社群反彈 | 三條 Ch3 主線皆完整 |
| **教條式對白** | 出戲、像簡報 | 用動作與細節展示 |
| **stat 語言進字幕** | 第四面牆破碎 | Trust +20 類禁入 `text` |

### 3.3 角色與邏輯

| 避免 | 後果 | LHTL 對照 |
|------|------|-----------|
| **主人 OOC**（突然變惡或聖人） | 差評「不像這個人」 | 25 歲上班族、第一次養狗 |
| **班表穿幫** | 敘事可信度崩 | `DEMO_DAY_CALENDAR` |
| **狗像道具** | 與系列核心衝突 | 感官 POV、choice-reactions |
| **取名前後代詞亂** | 細節差評 | 前「牠」、後他／她 |

### 3.4 商業與文案

| 避免 | 後果 | 對照 |
|------|------|------|
| **主線 <2h 付費章** | Steam 退款 | steam-release §2 |
| **夸大時長／分支** | 評論區反噬 | 全章總覽表可核對 |
| **標成 pure pet sim** | 期待錯位 | Story Rich + 輕互動 |
| **繁中後追、簡繁混** | 台灣市場直接差評 | tw-narrative-voice |

## 4. 讓 LHTL 敘事「值得買」的設計要點

以下為 **story-narrative 可執行** 的熱賣槓桿，對應 guide_line 差異化：

### 4.1 獨特賣點（Pitch 必保留）

1. **狗感官 POV**——`smell`、身體語言，Steam 上極少做滿三部曲。  
2. **中年篇（Ch2）**——被忽略的日常；競品多跳過。  
3. **跨作記憶**——Landmark 鎖定 → Ch3 個人化告別（類 *Steins;Gate* 長線 payoff）。  
4. **後果服務愛**——選錯可修，不養死（類 Telltale 但無 permadeath）。  
5. **基調三段**——暖 → 靜 → 克制；**眼淚來自時間**，非套路。

### 4.2 章節級敘事節奏（設計模板）

| 篇章 | Steam 玩家期待 | 敘事 Agent 必排 |
|------|----------------|-----------------|
| **Ch1** | 15 min hook、想繼續養 | Day 1 語調金標 + Day 2 取名 + Day 3 第一個「被記住」選擇 |
| **Ch1 全章** | 3–5h、多結局 | 全章總覽表、Landmark ≥3、每週笑暖 |
| **Ch2** | 不無聊的日常 | vignette 密度、被忽略／家庭變化、**不催淚** |
| **Ch3** | 有尊嚴的告別 | 三主線完整、內容警告、Ch1–2 閃回 **必須有對應 flags** |

### 4.3 高轉換的「記憶節點」設計公式

```
記憶節點 = 具體物件／地點 + 玩家選擇或動作 + 一句可引用台詞 + 相簿 desc
```

**範例（Ch1）：** 靠膝 Memory、責任書簽名、雷雨夜／靜日——每個都應能寫進 Steam 評論：「我還記得那天……」

### 4.4 分支設計：質 > 量

| 做法 | 原因 |
|------|------|
| 每章 **3–5 個真正重大選** | *Life is Strange* 玩家記住的是少數關鍵場 |
| 其餘用 **tier／reaction** 變體 | 避免假選項感，又控制場景爆炸 |
| 每條結局 **一句話可描述** | 商店「多結局」承諾可驗證 |
| 壞結局 **短、可重玩該週** | 不懲罰全系列 |

### 4.5 重玩與收集（敘事驅動）

- **相簿／日記**：每 Memory 2–4 句 **標題式散文**（類 *Spiritfarer* 日記）。  
- **Landmark 列表**：成就／全收集玩家要看得懂 **「還差哪個選擇」**（大綱須有條件表）。  
- **跨作**：Ch2 開場 **一句 callback** 到 Ch1 狗名／習慣——玩家感到「這是我的狗」。

## 5. 章節大綱審查：Steam 熱賣對照表

整章或新段落大綱完成後勾選：

### 5.1 Hook 與留存

- [ ] **前 15 分鐘**（或 Day 1）是否有明確情緒 hook？  
- [ ] 第一個 **Memory／重大選** 是否在玩家可能退款前出現（建議 Day 2–3）？  
- [ ] 是否有 **笑 + 暖** 讓 Ch1 不像 pure 催淚？

### 5.2 重量與誠實

- [ ] 重大選是否 **≤5 個／章** 且皆有 Landmark 或 flag？  
- [ ] 商店承諾的 **選擇／結局數** 能否在大綱找到？  
- [ ] 基調是否符合該章（Ch1 不死亡、Ch3 不搞笑過頭）？

### 5.3 密度與時長

- [ ] 全章總覽表主線 **>2h**、目標 **3–5h**？  
- [ ] 是否有 **灌水段**（無主題句、無必達事件）？  
- [ ] 每週是否 **≥1 笑 + ≥1 暖**？

### 5.4 差異化

- [ ] 本章是否有 **只有 LHTL 會寫** 的場景（狗 POV、班表、中年日常）？  
- [ ] 若拿掉狗 POV，故事是否變成 **generic 治癒 VN**？（若是，加强 smell／身體／跨作）

### 5.5 跨作與 Ch3 鋪墊

- [ ] 新 Landmark 是否標 **Ch3 引用方式**？  
- [ ] Ch2 揭露是否列 **contentWarning**？

## 6. 商店敘事文案：從熱賣作學什麼

### 6.1 短描述（一句話）

**熱賣公式：** `[獨特視角／關係] + [時間跨度] + [選擇後果] + [基調誠實]`

**LHTL 草案（見 guide_line §七）：**  
> 三部曲寫信任、日常與告別；選擇改變關係與記憶，**不會因一次失誤永遠失去牠**。

**避免：** 「最催淚的狗遊戲」「讓你哭到斷片」（Ch1 不符、差評風險）。

### 6.2 長描述（段落）

| 段落 | 寫什麼 | 熱賣參考 |
|------|--------|----------|
| 1 | 你是誰、狗是誰、**狗視角** | *Farewell North* 關係句 |
| 2 | **本章**時間跨度 + 主題 | 勿夸大三部曲全完 |
| 3 | 互動類型（選項、相簿、撫摸） | *Spiritfarer* 準備式 |
| 4 | 結局種類 + 時長 | 具體數字（3–5h） |
| 5 | 內容警告（Ch2／Ch3） | 誠實標籤 |

### 6.3 標籤與基調

- **主標籤：** Emotional、Story Rich、Choices Matter、Dogs  
- **勿過度依賴：** Visual Novel（若用，副標仍強調互動敘事）  
- **勿標：** Horror、Gore（除非真有；LHTL Ch3 用內容警告而非 horror 標籤）
